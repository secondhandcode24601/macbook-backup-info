Personal backup utility

MacBook Air Daily Backup

This is a personally operated tool for copying selected local files to the owner's Google Drive. It uses the open-source rclone command-line tool and a local schedule. It has no hosted application server and is not offered as a public backup service.

The backup uploads new and changed files, retains earlier copies of replaced files, and does not copy cloud archives back to the computer automatically. Its Google authorization is limited to specific Drive files used with the application.

Only the owner's device runs the backup. This website provides the public information required for its Google authorization; it provides no access to backup contents.
