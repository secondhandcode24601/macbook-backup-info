Privacy and data handling

MacBook Air Daily Backup is a single-user, personally operated backup utility. It has no service operator receiving users' files and no hosted application server.

Data used

The local backup process reads the owner's selected files and metadata to upload, compare and verify backup copies. It requests Google's drive.file permission: access to specific files created by or authorized for this application. It does not request unrestricted access to the owner's existing Drive contents.

Storage and transfer

Backup files are sent directly from the owner's device to the owner's Google Drive using rclone. File contents and retained versions are stored there under the owner's existing Google account. This public website does not contain or receive backup files, authentication tokens, private directory listings or backup status records.

OAuth credentials remain in a private configuration file on the owner's device. They are excluded from the file backup. The owner may also use their existing Codex account for an optional health monitor that reviews backup status and storage-use metadata; the transfer engine itself sends backup contents only to Google Drive.

Retention and control

Earlier copies of changed files are retained in the owner's Drive. Deleting a file locally does not automatically delete its cloud copy. The owner controls deletion and sharing through Google Drive and may revoke the application's authorization through Google Account settings. No backup content is intentionally made public by this utility.

Third-party services

Google handles Drive storage and authorization under its own policies. This static information website is hosted separately; its host may receive ordinary website access logs. The backup does not use those logs or send backup contents to this website's host.
